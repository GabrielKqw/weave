Architecture

Built for Engineering Discipline

Weave is not just an output filter. It provides a complete policy and memory layer for multi-agent workflows.

Terminal Intelligence

Domain-specific filters for Git, Test Runners (Jest, Vitest, Node test, Pytest, Cargo, Go), Search (grep/rg), and Linters. Compresses passing noise, caps streams at 20MB.

Failure Integrity

Non-zero exit codes always pass through 100% unreduced. Stack traces, assertion diffs, and error diagnostics are guaranteed to reach the AI model intact.

Preread Ledger

Tracks file reads and searches in .weave/ledger.json. If an agent repeatedly reads the same unchanged file, Weave warns it to use working memory instead.

Cross-Agent Memory

Freeze task context and architecture state with weave memory save <name>. Other agents or future sessions restore it instantly without burning chat tokens.

CLI Reference

Complete Command Reference

All commands available via weave <command> or node cli/weave.js <command>.

weave doctor Diagnostic

Verifies Node.js version (>=18), bash path, plugin manifests, and directory permissions.

weave doctor [--agent=claude|codex|agy]
weave exec Core

Executes a shell command through Weave's output reduction filters with 100% failure integrity.

weave exec -- <command>
weave memory Context

Saves, restores, lists, and manages named snapshots of .weave/state.md.

weave memory <save|load|list|show|delete> [name]
weave gain Metrics

Reports total byte reduction and estimated tokens saved across all recorded runs.

weave gain [--history]
weave recall Audit

Prints the complete raw captured output for any omitted run by its 12-character run ID.

weave recall <run-id>
weave mode Policy

Switches active engineering policy: off, lite, full, or ultra.

weave mode [off|lite|full|ultra]

Changelog & Release History

Track new features, bug fixes, and improvements across every Weave release.

v0.5.1 Latest Release

Context Snapshots, Secret Redaction & Hook Hardening

  • Added weave memory CLI: Full context snapshot management (save, load, list, show, delete) with symlink and path traversal protection.
  • Hardened Secret Redaction: Added regex scrubbing for bare JSON Web Tokens (JWT) starting with eyJ without requiring a Bearer prefix.
  • BOM Header Handling: Fixed hooks silently failing on BOM-prefixed JSON stdin on Windows environments.
  • Test Suite Expansion: 128 passing unit and integration tests across Linux and Windows runners.
