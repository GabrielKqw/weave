How to Use Weave Step-by-Step

Follow this simple cycle to eliminate terminal noise, prevent context loss, and persist task memory between tools and agents.

Step 1: Diagnostics

Verify Your Environment with `doctor`

Before starting, make sure your Node.js runtime, Git Bash, and plugin manifests are healthy. Weave validates write permissions in `.weave/` without modifying your project files. 

node cli/weave.js doctor
Expected Terminal Output: 
OK    detected agent - codex
OK    node runtime - v24.15.0
OK    bash executable - C:\Program Files\Git\bin\bash.exe
OK    .claude-plugin/plugin.json - present
OK    .weave/ writable - OK
Step 2: Execution

Execute Commands Through `exec`

Run test runners, Git commands, or linters through Weave. If the command succeeds, hundreds of lines of noise collapse into a 2-line summary. If it fails, 100% of the stack trace and errors are kept intact. 

# Test suite compression:
node cli/weave.js exec -- npm test

# Git status without noise:
node cli/weave.js exec -- git status
Expected Terminal Output: 
Command: npm test
Exit: 0
Summary: test suite passed (34 tests passed, 0 failures)
Omitted: 284 line(s) (95.8% output reduced)
Recovery: weave recall 4f12ab90cd34
Step 3: Context Memory

Freeze & Hand Off Context with `memory`

Never re-explain architecture or rules across chat sessions. Save a snapshot of your task and load it into another session or another tool (Claude Code, Codex, or Antigravity) with zero token waste. 

# Save the current task contract & working memory:
node cli/weave.js memory save auth-module

# List saved memory snapshots:
node cli/weave.js memory list

# In another session, restore the context:
node cli/weave.js memory load auth-module
Expected Terminal Output: 
Saved memory "auth-module" -> .weave/memories/auth-module.md
# When loading:
Loaded memory "auth-module" -> .weave/state.md (Context restored in 250 tokens)
Step 4: Scoreboard

Inspect Measured Token Savings with `gain`

Weave stores local metrics for all wrapped executions in `.weave/runs/`. Run `gain` to verify exactly how many bytes and tokens your project saved. 

# Aggregate savings scoreboard:
node cli/weave.js gain

# Detailed historical log of all runs:
node cli/weave.js gain --history
Expected Terminal Output: 
Weave gain - command output reports only
Commands recorded:  48
Original bytes:     184.2 KB
Report bytes:       14.8 KB
Reduction:          91.9%
Approx tokens saved: ~42,350 tokens

CLI Reference

Complete Command Reference

Explore what each Weave command does, its exact syntax, real-world examples, and expected output.

weave doctor Diagnostic

Verifies Node.js runtime (>=18), bash path, plugin manifests integrity, and directory write permissions.

Syntax:
weave doctor [--agent=claude|codex|agy]
Real Example: 
node cli/weave.js doctor
weave exec Core

Executes any shell command through output reduction filters. Preserves non-zero exit codes, errors, and stack traces 100% verbatim.

Syntax:
weave exec [--cwd=<dir>] -- <command>
Real Example: 
node cli/weave.js exec -- npm test
weave memory Context

Saves, restores, lists, and manages named snapshots of `.weave/state.md` under `.weave/memories/` for cross-agent task handoff.

Syntax:
weave memory <save|load|list|show|delete> [name]
Real Example: 
node cli/weave.js memory save auth-v1
weave gain Metrics

Calculates total byte reduction and approximate tokens saved across all wrapped runs in `.weave/runs/`.

Syntax:
weave gain [--history]
Real Example: 
node cli/weave.js gain --history
weave recall Audit

Prints the full, raw captured output of any past command by its 12-character run ID, with automatic secret scrubbing.

Syntax:
weave recall <run-id>
Real Example: 
node cli/weave.js recall 4f12ab90cd34
weave mode Policy

Displays or updates the active engineering discipline policy in `.weave/mode`: `off`, `lite`, `full`, or `ultra`.

Syntax:
weave mode [off|lite|full|ultra]
Real Example: 
node cli/weave.js mode full
weave discover Analysis

Parses past local Claude session transcripts (`.jsonl`) to retrospectively estimate compressible output missed before Weave was active.

Syntax:
weave discover
Real Example: 
node cli/weave.js discover

v0.5.1 Latest Release

Context Snapshots, Secret Redaction & Hook Hardening

  • Added weave memory CLI: Full context snapshot management (save, load, list, show, delete) with symlink and path traversal protection.
  • Hardened Secret Redaction: Added regex scrubbing for bare JSON Web Tokens (JWT) starting with eyJ without requiring a Bearer prefix.
  • BOM Header Handling: Fixed hooks silently failing on BOM-prefixed JSON stdin on Windows environments.
  • Test Suite Expansion: 128 passing unit and integration tests across Linux and Windows runners.
